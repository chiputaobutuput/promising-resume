# 冯小叶个人网站内容维护

内容依据用户提供的《冯小叶网站简历.docx》整理，未添加未提供的项目成果、客户或外链。

2026 年 9 月更新：补充特斯联大模型提示词评测与迭代经历、AI 工作流工具、完整奖学金与竞赛荣誉，并依据《获奖证书.pdf》核对代表性证书。证书在网页中以文字索引展示，不公开整页扫描件。

- `src/App.tsx`：首页介绍、署名、联系方式。
- `src/ui/Resume.tsx`：按原简历的教育背景、实践经历、项目经历、校园经历、个人技能五章展示；顺序与现有五个 3D 对焦点一一对应。
- `src/data/works.ts`：按相同的五章组织详细内容入口。
- `src/content/works/*.md`：每个案例的详细文字，可在此补充已获准展示的截图或项目链接。
- `src/styles.css`：页面与手机端样式。

保留现有模型、镜头、对焦、人物与眼睛动效。首页淡出改为按整屏滚动计算，以适配新的文案高度；降低胶片噪点强度，提升内容可读性。详细内容适度压缩重复表述，但保留职责、行动、方法和量化结果。

硕士时间展示至 2027 年 6 月；论文为已录用、专利为已受理；大促 GMV 为活动整体成果。奖项名称沿用简历原文。

修改前的页面源码保存在仓库根目录 `backups/before-resume-content.tar.gz`。

构建：在 web 目录运行 `npm run build`，部署产物在 dist。本次只修改本地网站，未发布。
